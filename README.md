# FLASH SWIM

Сайт школы плавания FLASH SWIM: занятия и цены, расписание, тренеры, спортивные сборы, отзывы и запись. Статический HTML/CSS/JavaScript, без сборки и сторонних npm-зависимостей. Готовый сайт находится в `dist/`.

Репозиторий проекта: https://github.com/wimyazaica/flasswim.

## Локальный запуск

Нужен Node.js 18 или новее. Из корня проекта выполните:

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Устанавливать npm-пакеты не требуется.

## Версия для передачи коллеге

```sh
node scripts/prepare-preview.mjs ./preview
```

Откройте `preview/index.html` двойным щелчком после полного извлечения папки из ZIP. Установка программ и запуск сервера для просмотра не нужны. После изменений повторите экспорт. Настройки первого экрана встраиваются в HTML, поэтому видео работает и при открытии файла без сервера.

Видео, фотографии, шрифты и анимации хранятся локально. Для живой карты, построения маршрутов, отзывов Яндекса, переходов в WhatsApp и Telegram нужен интернет.

## Первый экран

Текст расположен слева, одно тихое видео — справа. У него нет звука, кнопок управления, подписей и переключения материалов. Два скрытых проигрывателя одного исходника обеспечивают плавное растворение между повторениями.

Используется чистый фрагмент тренировок в бассейне с 0 до 14,8 секунды. Исходный MP4 сохранён без изменений. Нижние 110 пикселей встроенных титров скрыты CSS-кадрированием: область видео имеет пропорции 916 × 402. Сцены ОФП с верхними титрами не воспроизводятся. Постер взят из настоящего кадра на 6-й секунде ролика.

При запрете автозапуска, ошибке загрузки или включённом системном уменьшении движения вместо видео показывается фотография команды. При уходе со страницы или прокрутке первого экрана из области видимости проигрывание останавливается.

## Где менять содержимое

| Файл | Содержимое |
| --- | --- |
| `dist/index.html` | Тексты, цены, структура, фотографии по разделам, галерея сборов, контакты, ссылки на оферту и политику |
| `dist/app.js` | Два бассейна, расписание, тренеры, выбор дня и времени, кнопки записи, живая карта и маршруты |
| `dist/hero-media.json` | Источник видео, постер, границы чистого фрагмента, длительность растворения и данные резервной фотографии |
| `dist/hero-media.js` | Тихий повтор видео с двумя проигрывателями, растворение, пауза вне экрана и поддержка уменьшения движения |
| `dist/hero-layout.css` | Первый экран: текст слева, видео справа, кадрирование встроенных титров и адаптивная верстка |
| `dist/camp-gallery.js`, `dist/camp-gallery.css` | Пять фотографий сборов с анимированным листанием внутри сайта |
| `dist/moments.css` | Фотографии рядом с информацией о занятиях, бассейне и тренерах |
| `dist/locations.css` | Живая Яндекс-карта и форма построения маршрута |
| `dist/ocean.css`, `dist/readability.css` | Бирюзовая тема, читаемость и адаптивная верстка |
| `dist/swim-motion.js`, `dist/swim-motion.css` | Натуральные движения пловцов, четыре стиля плавания и дорожки без текстовых подписей |
| `dist/assets/` | Исходное видео, постер, фотографии, шрифты и лицензия шрифта |

В разделе «Сборы» пять фотографий. Их можно листать нажатием на фото, стрелками, миниатюрами, клавиатурой или свайпом. Ссылок на открытие фотографии вне сайта нет. Отдельного раздела «Фото» нет: остальные фотографии распределены по информационным разделам, командный снимок служит резервным изображением первого экрана.

Кнопки записи открывают реальные контакты школы в WhatsApp или Telegram с выбранными форматом, бассейном, днём и временем. Запись подтверждает администратор; отдельного сервера приёма заявок нет.

Внизу расположены живая карта Яндекса в iframe и виджет отзывов. Можно выбрать один из двух бассейнов, ввести начальный адрес и построить маршрут на машине, общественном транспорте или пешком. Маршрут показывается на карте; отдельная ссылка открывает его в Яндекс Картах. Адрес отправления не сохраняется сайтом и передаётся Яндексу для построения маршрута.

Бесплатный виджет Яндекс Карт может показывать рекламу. Интерфейс и реклама Яндекса не скрываются. Для гарантированного отключения рекламы нужен соответствующий тариф Яндекса и API-ключ. Время занятий и наличие мест следует подтверждать у администратора.
