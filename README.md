# FLASH SWIM

Сайт школы плавания FLASH SWIM: занятия и цены, расписание, тренеры, спортивные сборы, отзывы и запись. Статический HTML/CSS/JavaScript, без сборки и сторонних npm-зависимостей. Готовый сайт находится в `dist/`.

Репозиторий проекта: https://github.com/wimyazaica/flasswim.

## Локальный запуск

Нужен Node.js 18 или новее. Из корня проекта выполните:

```sh
npm run dev
```

Откройте http://127.0.0.1:4173. Устанавливать npm-пакеты не требуется.

## Версия для передачи коллеге

```sh
node scripts/prepare-preview.mjs ./preview
```

Откройте `preview/index.html` двойным щелчком после полного извлечения папки из ZIP. Установка программ и запуск сервера для просмотра не нужны. После изменений повторите экспорт. Настройки первого экрана встраиваются в HTML, поэтому видео работает и при открытии файла без сервера.

Видео, фотографии, шрифты и анимации хранятся локально. Для живой карты, построения маршрутов, отзывов Яндекса, переходов в WhatsApp и Telegram нужен интернет.

## Первый экран

Тихий видеофон занимает весь первый экран. Бирюзовое затемнение сохраняет читаемость текста. У видео нет звука, кнопок управления, подписей и переключения материалов. Два скрытых проигрывателя одного исходника обеспечивают плавное растворение между повторениями.

Используется чистый фрагмент тренировок в бассейне с 0 до 14,8 секунды. Исходный MP4 сохранён без изменений. Нижние 110 пикселей встроенных титров скрыты кадрированием. `ResizeObserver` рассчитывает размер внутренней рамки с пропорциями 916 × 402, чтобы фон покрывал первый экран при изменении размеров окна, а исходные пропорции видео сохранялись. Сцены ОФП с верхними титрами не воспроизводятся. Постер взят из настоящего кадра на 6-й секунде ролика.

При запрете автозапуска, ошибке загрузки или включённом системном уменьшении движения вместо видео показывается фотография команды. При уходе со страницы или прокрутке первого экрана из области видимости проигрывание останавливается.

В разделе «Сборы» пять фотографий. Их можно листать нажатием на фото, стрелками, миниатюрами, клавиатурой или свайпом. Ссылок на открытие фотографии вне сайта нет. Отдельного раздела «Фото» нет. Фотографии размещены за четырьмя карточками цен; отдельное фото в расписании убрано. Командный снимок служит резервным изображением первого экрана.

## Анимации плавания

Процедурные SVG-фигуры заменены готовыми 3D-циклами баттерфляя, плавания на спине, брасса и кроля. Каждый цикл состоит из 24 исходных кадров; позы и интервалы взяты из GIF-анимаций Fxqf и редакторов Wikimedia Commons. Фон и линия воды удалены, добавлена прозрачность, плавки перекрашены в красный цвет. Производные PNG-атласы и выбранные исходники распространяются по CC BY-SA 3.0. Полная атрибуция находится в `dist/credits.html` и `dist/assets/SWIM-ANIMATION-LICENSE.txt`.

Атласы уже подготовлены и включены в сайт. Проигрыватель рисует их на canvas без `getImageData` и загрузки конфигурации через `fetch`, поэтому анимации работают и при открытии `index.html` через `file://`. На стороне посетителя не нужны Python, обработка GIF или дополнительные библиотеки. Скрипт `tools/prepare-swim-atlases.py` предназначен только для необязательной переподготовки медиа и умеет брать исходники из включённой папки `dist/assets/swim-sources/`. Для его запуска нужны Python и Pillow:

```sh
python tools/prepare-swim-atlases.py
```

Кнопки записи открывают реальные контакты школы в WhatsApp или Telegram с выбранными форматом, бассейном, днём и временем. Запись подтверждает администратор; отдельного сервера приёма заявок нет.

Внизу расположены живая карта Яндекса в iframe и виджет отзывов. Можно выбрать один из двух бассейнов, ввести начальный адрес и построить маршрут на машине, общественном транспорте или пешком. Маршрут показывается на карте; отдельная ссылка открывает его в Яндекс Картах. Адрес отправления не сохраняется сайтом и передаётся Яндексу для построения маршрута.

Бесплатный виджет Яндекс Карт может показывать рекламу. Интерфейс и реклама Яндекса не скрываются. Для гарантированного отключения рекламы нужен соответствующий тариф Яндекса и API-ключ. Время занятий и наличие мест следует подтверждать у администратора.
